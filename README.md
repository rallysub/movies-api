# Movies API

## Описание проекта

Movies API — это небольшое приложение для работы с каталогом фильмов. С его помощью можно получать список фильмов, смотреть информацию об отдельном фильме, добавлять новые записи, изменять их и удалять.

Проект написан на Python с использованием FastAPI.

## Возможности

- Получение списка фильмов
- Поиск фильма по его ID
- Добавление фильма
- Полное и частичное изменение информации о фильме
- Удаление фильма
- Проверка данных при создании и изменении записей

## Технологии

- Python
- FastAPI
- Uvicorn
- SQLAlchemy
- SQLite
- aiosqlite
- Pydantic
- Alembic

## Быстрый старт

### 1. Клонирование репозитория

```bash
git clone https://github.com/rallysub/movies-api.git
cd movies-api
```

### 2. Создание виртуального окружения

```bash
python -m venv .venv
```

Для Windows:

```bash
.venv\Scripts\activate
```

Для Linux и macOS:

```bash
source .venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Применение миграций

```bash
alembic upgrade head
```

### 5. Запуск приложения

```bash
uvicorn src.main:app --reload
```

После запуска API будет доступно по адресу http://127.0.0.1:8000.

Документация:
- Swagger: http://127.0.0.1:8000/docs
- ReDoc: http://127.0.0.1:8000/redoc

## Основные эндпоинты

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/` | Проверяет, что приложение запущено |
| GET | `/movies/` | Возвращает список фильмов |
| GET | `/movies/{movie_id}` | Возвращает фильм по ID |
| POST | `/movies/` | Добавляет фильм |
| PUT | `/movies/{movie_id}` | Полностью обновляет фильм |
| PATCH | `/movies/{movie_id}` | Изменяет отдельные поля фильма |
| DELETE | `/movies/{movie_id}` | Удаляет фильм |

Если фильм с указанным ID не найден, API возвращает ошибку `404`.

Пример данных для добавления фильма:

```json
{
  "title": "The Matrix",
  "genre": "Sci-Fi",
  "rating": 8.7,
  "year": 1999
}
```

## Фильтрация и сортировка

В репозитории предусмотрены параметры для фильтрации и сортировки списка:

- `year_min` — год не меньше указанного;
- `year_max` — год не больше указанного;
- `min_rating` — минимальный рейтинг;
- `order_by` — поле сортировки;
- `limit` — количество записей;
- `offset` — смещение списка.

Для сортировки доступны поля `title`, `year`, `rating` и `id`. Чтобы сортировать по убыванию, перед названием поля ставится дефис, например `-rating`.

Обрати внимание: в текущем роутере параметры фильтрации и сортировки пока не передаются в функцию репозитория. Поэтому через API сейчас работает получение списка с пагинацией, а фильтры требуют дополнительного подключения.

## Модель данных

В таблице `movies` хранятся следующие поля:

| Поле | Тип | Описание |
|---|---|---|
| `id` | Integer | ID фильма, первичный ключ |
| `title` | String | Название |
| `genre` | String | Жанр |
| `rating` | Float | Рейтинг |
| `year` | Integer | Год выпуска |

При проверке данных используются ограничения:
- название: от 2 до 200 символов;
- жанр: от 2 до 100 символов;
- рейтинг: от 0 до 10;
- год выпуска: от 1888 до текущего года.

## Ограничения базы данных

- `id` является первичным ключом.
- Поля `title`, `genre`, `rating` и `year` обязательны (`NOT NULL`).
- Для `id` и `title` предусмотрены индексы.
- База данных проекта — SQLite.

Проверка диапазона рейтинга и года выполняется в Pydantic-схемах. В текущей миграции эти ограничения не заданы как `CHECK`-ограничения самой базы данных.
